Отчетность по иностранным работникам

Документом регистрируется оформляемые документы иностранных граждан, при приеме на работу в организацию для сдачи отчетности в контролирующие органы.

Реквизиты

  • Организация — работники которых вводится в табличной части документа.
  • Событие — по которым заполняется виды действий в табличной части документа.
  • Контролирующий орган (скрытый реквизит) — государственный орган, в который предоставляются формы отчетности. Используется для тех форм, в которых контролирующий орган не указан явно в справочнике Действия по событиям учета иностранных работников в реквизите «Контролирующий орган».
  • Оформил — сотрудник, назначенный ответственным за сдачу отчетности по иностранным работникам в регистре «Ответственный за работу с иностранными работниками».
  • Руководитель — сотрудник, который указан руководителем организации в справочнике «Организации».
  • Должность — должность сотрудника, указанного в реквизите «Руководитель».

Выполняемые действия

Кнопки табличной части:

  • Заполнить по событию — заполняет табличную часть «Выполняемые действия» работниками и необходимыми действиями, если они еще не были выполнены, в зависимости от настроек, выбранного «События» и организации:
    1. Прибытие — сотрудники, для которых задана дата прибытия, которая меньше или равна дате документа и сотрудник не уволен на дату документа;
    2. Прием на работу — сотрудники, для которых указано гражданство, отличное от Российской Федерации на дату документа и оформлен документ приёма на работу;
    3. Увольнение — сотрудники, для которых указано гражданство, отличное от Российской Федерации на дату документа и оформлен документ увольнения;
    4. Убытие — сотрудники, для которых задана дата убытия, которая меньше или равна дате документа;
    5. Прочее — сотрудники, для которых указано гражданство, отличное от Российской Федерации на дату документа.

    Общие условия, для заполнения по событиям

    • Для работника должны быть заполнены данные записи в справочнике Сотрудник по гиперссылке «Иностранный работник» и отключен флаг «В документы добавлять вручную» на дату документа.
    • Для статуса иностранца, режима въезда и события должны быть настроены соответствующие действия в справочнике «Действия по событиям учета иностранных работников».
  • Заполнить значение параметра — заполнение значений одного из параметров для всех строк табличной части «Выполняемые действия». Используется в случае, когда для большого количество работников нужно заполнить дополнительные данные одинаковыми значениями параметра.

Реквизиты табличной части:

  • № — номер строки в табличной части документа.
  • Действие — заполняется видами действий по учету иностранных граждан.
  • Сотрудник — заполняется сотрудниками вышеуказанной организации.
  • Документ — заполняется автоматически при выборе действий по учету иностранных граждан.
  • Выполнено — устанавливается, если текущее действие выполнено.
  • Дата выполнения — дата выполнение текущего действие по учету иностранных граждан.

Дополнительные данные

В этой табличной части, заполняются дополнительные параметры для некоторых форм отчетности, если это требуется.
