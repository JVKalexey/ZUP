Выводит информацию о сотрудниках, имеющих патент, и данные по последним оплатам патентов. В отчет попадают только те сотрудники, у которых имеется действующий патент на указанный период. Если включен учет нескольких патентов, по каждому патенту работника выводится своя строка, патенты различаются разрезом.

Параметры отчета:

  • Организация — организация, по которой будет производиться отбор сотрудников и документов «Патент».
  • Период — период отбора документов «Патент».

Показатели отчета об информации о патентах иностранного гражданина:

Показатель

Результат показателя

Организация

Организация в которой работает или будет работать иностранный работник.

Сотрудник

Иностранный работник, элемент справочника «Физические лица».

Документ, удостоверяющий личность

Документ, удостоверяющий личность иностранного гражданина, внесенный при оформлении работника в справочнике «Сотрудники».

Патент

Документ, внесенный в регистр сведений «Документы иностранного работника» при оформлении работника в организацию в справочнике «Сотрудник».

Разрез

Разрез, в котором учитывается патент. Позволяет различать несколько одновременно действующих патентов одного работника. Незаполненный разрез означает основной патент. Данные об оплате подбираются к патенту по разрезу, поэтому суммы и даты оплаты не смешиваются между патентами.

Дата оплаты

Дата документа «Квитанция за патент».

Сумма оплаты

Сумма оплаты за патент, указанная в документе «Квитанция за патент».



В форме расположены команды управления отчетом, поле «быстрых» пользовательских настроек и поле результата отчета.

При открытии в поле «быстрых» пользовательских настроек выводятся текущий перечень параметров (текущего варианта настроек), по которым возможен отбор данных для построения отчета. В список «быстрых» пользовательских настроек данного отчета включаются только те параметры, которые определены для этого при конфигурировании, а также те, для которых в пользовательских настройках каждого такого параметра указан режим «Быстрый доступ».

Для редактирования полного перечня текущих настроек выполните команду «Настройки». В открывшейся форме выполняется формирование условий отбора для построения отчета. Для более тонкой настройки отчета выберете «Расширенный» вид отчета. Устанавливая или снимая флажки для параметров, а также изменяя условия сравнения и значения сравнения, можно оперативно получать различные срезы данных.

Отчет может содержать несколько вариантов настроек отчета. Система позволяет сохранять созданные варианты настроек по команде «Еще → Варианты отчета → Сохранить вариант». Для открытия сохраненного варианта настроек воспользоваться командой «Еще → Варианты отчета» и выбрать сохраненный ранее вариант.

Если требуется изменить существующий вариант, выполните команду «Еще → Прочее → Изменить вариант отчета». В открывшейся форме измените настройки отчета и сохраните свой выбор по кнопке «Завершить редактирование».

Если требуется вернуться к «стандартным» значениям отчета (значения, которые сохранены для текущего варианта настроек), выполните команду «Еще → Стандартные настройки».

Для построения отчета нажмите кнопку «Сформировать».

Результат выводится в поле табличного документа. В верхней части которого указываются применяемые для данного построения значения параметров отбора.

Результат отчета может быть сохранен в файл, а также распечатан.
