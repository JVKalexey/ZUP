Дополнительный параметр печати

Хранит перечень дополнительных параметров печати, которые могут использоваться про оформлении форм отчётности в случаях, когда данных, содержащихся в справочниках для формы отчётности недостаточно.

Реквизиты

  • Наименование — наименование параметра печати. Будет отображаться при заполнении документа Отчетность по иностранным работникам.
  • Тип значения — тип значения параметра печати.
  • Поле адреса — если включено, то при выборе значения будет открываться форма ввода адреса. Тип значения должен быть строка.
  • Имя параметра — имя параметра, под которым параметр будет доступен в макетах форм отчетности. Имя параметра может содержать только цифры и русские буквы и не может начинаться с цифры.
