Справочник содержит отчетные формы документов для сдачи обязательной отчетности при работе с иностранными гражданами, утвержденные законодательно на территории Российской Федерации.

Приведенные формы отчетности доступны для редактирования.

Пояснения по заполнению некоторых данных в печатных формах

  • Паспорт иностранного работника — паспортные данные работника (физического лица) из справочника Сотрудники на дату документа «Отчетность по иностранным работникам».
  • Ответственный за работу с иностранными работниками — определяется из реквизита «Оформил» документа «Отчетность по иностранным работникам».
  • Адрес постановки на учет/адрес регистрации по месту жительства — адрес по прописки работника (физического лица), внесенный в справочнике Сотрудник.
  • Профессия — должность, на которую принят иностранный работник.
  • ИНН — берется из записи регистра сведений «Документы иностранных работников» с видом документа «ИНН» на дату документа «Отчетность по иностранным работникам». Если данных нет, то ИНН определяется из справочника физических лиц.
  • Адрес работы — определяется из (в порядке убывания приоритета): 1) адрес работы в дополнительных параметрах печати документа «Отчетность по иностранным работникам»; 2) фактический адрес организации.

Оформление убытия



Уведомление о прибытии

  • Вид и реквизиты документа, подтверждающего право на пребывание (проживание) в Российской Федерации (Виза) — заполняется из записи в справочнике Сотрудник по гиперссылке «Документы иностранного работника» с видом документа «Виза» на дату документа «Отчетность по иностранным работникам».
  • Вид и реквизиты документа, подтверждающего право на пребывание (проживание) в Российской Федерации (Вид на жительство) — заполняется из записи в справочнике Сотрудник по гиперссылке «Документы иностранного работника» с видом документа «Вид на жительство» на дату документа «Отчетность по иностранным работникам».
  • Вид и реквизиты документа, подтверждающего право на пребывание (проживание) в Российской Федерации (Разрешение на временное проживание) — заполняется из записи в справочнике Сотрудник по гиперссылке «Документы иностранного работника» с видом документа «Разрешение на временное проживание» на дату документа «Отчетность по иностранным работникам».
  • Срок пребывания до — заполняется из записи в справочнике Сотрудник по гиперссылке «Иностранный работник» поле «Дата убытия».
  • Адрес прежнего места пребывания в РФ — заполняется из дополнительных данных документа «Отчетность по иностранным работникам».
  • Сведения о месте пребывания — адрес организации с видом «Фактический адрес».
  • Сведения о принимающей стороне — данные физического лица, который указан руководителем в справочнике «Организации».
  • Наименование и реквизиты документа, подтверждающего право пользования жилым или иным помещением — заполняется из дополнительных данных документа «Отчетность по иностранным работникам».

Разрешение на работу

  • Наименование территориального органа МВД России — заполняется из (в порядке убывания приоритета) 1) справочника «Действия по событиям» поля элемента соответствующего события «Контролирующий орган»; 2) скрытого реквизита «Контролирующий орган» документа «Отчетность по иностранным работникам».
  • Сроки действия разрешения на работу — заполняется из дополнительных данных документа «Отчетность по иностранным работникам».
  • Сведения об изменении ФИО — заполняется из дополнительных данных документа «Отчетность по иностранным работникам».
  • Адрес постоянного проживания — адрес по прописке в паспорте иностранного гражданина, который внесен в поле «Адрес по прописке» в личных данных в справочнике «Сотрудники».
  • Предполагаемый адрес постановки на миграционный учет по месту пребывания — адрес организации, в которую будет оформлен на работу иностранный гражданин.
  • Дополнительные сведения о работодателе, заказчике работ (услуг) — данные по организации, в которую будет оформлен иностранный гражданин, указанных в справочнике «Организации» в поле «Дополнительные реквизиты».

Оформление патента

  • Сведения об изменении ФИО — заполняется из дополнительных данных документа «Отчетность по иностранным работникам».
  • Документ, подтверждающий владение русским языком — заполняется из записи в справочнике Сотрудник по гиперссылке «Документы иностранного работника» с видом документа «Документ о владении русским языком» на дату документа «Отчетность по иностранным работникам».
  • Адрес постоянного проживания — адрес по прописке в паспорте иностранного гражданина, который внесен в поле «Адрес по прописке» в личных данных в справочнике «Сотрудники».
  • Адрес постановки на учет по месту пребывания — адрес работника (физического лица) с видом контактной информации «Адрес по прописке».
  • Срок постановки на учет по месту пребывания — заполняется из записи в справочнике Сотрудник по гиперссылке «Документы иностранного работника» соответствующими датами выдачи и срока действия документа иностранного работника «Регистрация по месту пребывания» на дату документа «Отчетность по иностранным работникам».
  • Документ, подтверждающий владение русским языком, знание истории России и основ законодательства Российской Федерации — заполняется из записи в справочнике Сотрудник по гиперссылке «Документы иностранного работника» с видом документа «Документ о владении русским языком» на дату документа «Отчетность по иностранным работникам».
  • Предполагаемый срок осуществления трудовой деятельности в Российской Федерации — заполняется из данных по работнику в справочнике Сотрудники, заполненных по гиперссылке «Иностранный работник» в поле «Дата окончания работы».
  • Ранее выданный патент — берется из записи в справочнике Сотрудник по гиперссылке «Документы иностранного работника» с видом документа «Патент» на дату документа «Отчетность по иностранным работникам» минус один день.

Заключение/расторжение трудового договора

  • Дата постановки на миграционный учет — заполняется из записи в справочнике Сотрудник по гиперссылке «Документы иностранного работника» соответствующей датой выдачи документа иностранного работника «Регистрация по месту пребывания» на дату документа «Отчетность по иностранным работникам.
  • Наименование территориального органа МВД России — заполняется из (в порядке убывания приоритета) 1) справочника «Действия по событиям» поля элемента соответствующего события «Контролирующий орган»; 2) скрытого реквизита «Контролирующий орган» документа «Отчетность по иностранным работникам».
  • ОКВЭД — заполняется из справочника «Организации» поле «ОКВЭД ред.2».
  • Сведения о работодателе — заполняются в соответствии с указанными данными по предприятию в справочнике «Организации».
  • Миграционная карта — заполняется из записи в справочнике Сотрудник по гиперссылке «Документы иностранных работников» с видом документа «Миграционная карта» на дату документа «Отчетность по иностранным работникам».
  • Дата заключения трудового договора — дата приёма на работу.
  • Дата расторжения трудового договора — дата увольнения.
  • Разрешение на работу — заполняется из записи в справочнике Сотрудник по гиперссылке «Документы иностранных работников» с видом документа «Разрешение на работу» или «Патент» на дату документа «Отчетность по иностранным работникам».
  • Предполагаемый срок осуществления трудовой деятельности — «планируемая дата окончания трудовой деятельности» из записи в справочнике Сотрудник по гиперссылке «Дополнительные данные иностранных работников». Если данных нет, то берется из срока действия разрешения на работу.
  • Адрес места осуществления трудовой деятельности принятого на работу иностранного гражданина — заполняется дополнительных данных документа «Отчетность по иностранным работникам» поле Адрес работы.

Убытие

  • Сведения о месте пребывания — заполняется из дополнительных данных документа «Отчетность по иностранным работникам».
