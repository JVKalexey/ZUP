Справочник предназначен для хранения информации о видах документов работников, являющихся иностранными гражданами. Данные справочника используются при заполнении печатных форм отчетности по иностранным работникам.

Имеет следующие предопределенные виды документов:

  • виза;
  • документ о владении русским языком;
  • ИНН;
  • миграционная карта;
  • иностранный паспорт;
  • патент;
  • полис добровольного медицинского страхования;
  • регистрация по месту пребывания;
  • разрешение на работу.

При заполнении статуса и режима въезда в РФ иностранных работников в табличной части справочника, можно автоматически создавать документы, удовлетворяющим этим условиям при создании записи иностранного гражданина в справочниках Физические лица и Сотрудники.

По кнопке «Создать» можно добавлять новые виды документов, используемые в работе при ведении учета иностранных работников.
