Вид документа иностранного работника

В справочнике хранятся виды документов иностранных работников для дальнейшего их использовании в справочнике Сотрудники для внесения информации по документам иностранных граждан.

Реквизиты

  • Наименование — наименование вида документа, например, виза или патент.
  • Обязательный — флаг устанавливается для документов, которые должны автоматически добавляться в список при занесении нового иностранного работника.
  • Напоминать об окончании — количество дней до истечения срок действия документа, за которое нужно вывести напоминание. Если указать 0, то напоминание не будет выводиться.
  • Использовать дополнительное поле — флаг устанавливается в том случае, если стандартных реквизитов документа не хватает. В таком случае можно использовать ещё один дополнительный реквизит. Например, для документа о владении русским языком это будет наименование этого документа.
    • Название дополнительного поля — заголовок дополнительного поля, под которым оно будет отображаться при заполнении реквизитов документа иностранного работника.

Табличная часть

В случае, если для вида документа установлен флаг "Обязательный", нужно указать для каких видов иностранных работников должно происходить автоматическое добавление этого вида документа.
