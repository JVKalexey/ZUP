Справочник хранит разрезы, по которым разделяются несколько однотипных документов одного иностранного работника.

Для чего нужен

Обычно у работника один документ каждого вида: один патент, одна миграционная карта. Но патентов может быть несколько одновременно:

  • работник трудится в нескольких субъектах Российской Федерации. Патент действует только в том субъекте, где выдан, поэтому для работы в другом регионе оформляется отдельный патент;
  • в патентах указана профессия. Если высшее должностное лицо субъекта Российской Федерации установило такое требование, работать можно только по указанной профессии, и для совмещения должностей нужны разные патенты.

Чтобы программа могла хранить такие патенты одновременно, каждому из них назначается свой разрез.

Как заполнять

Заведите столько элементов, сколько параллельных документов требуется различать, и назовите их понятно для себя: Москва и Московская область, если патенты получены в разных субъектах, либо Повар и Водитель, если различаются профессии.

Незаполненный разрез — это тоже разрез. Он означает основной документ. Если работник обходится одним патентом, разрез у него остается пустым, и заполнять справочник не нужно.

Где используется

  • документы иностранного работника — разделение нескольких патентов;
  • квитанция за патент — указывает, за какой из патентов внесен платеж;
  • отчетность по иностранным работникам — определяет, какой патент попадет в печатную форму;
  • отчеты по патентам — разделяют сроки и суммы по каждому патенту.

Как включить

Справочник доступен, когда в настройках программы включены Учет патентов и Учет нескольких патентов у одного работника.
