Действие по событиям

Справочник предназначен для хранения информации о действиях, которые нужно произвести при событиях, таких как прием на работу, прибытие и т.д., при учете иностранных граждан.

Этот справочник упрощает заполнение табличной части документа Отчетность по иностранным работникам, используется при нажатии на кнопку «Заполнить по событию».

Реквизиты

  • Наименование — наименование действия, например «Оформление патента».
  • Вид оформляемого документа — форма отчетности, которая оформляется данным действием.
  • Контролирующий орган — государственный орган, в который предоставляется оформляемая форма отчетности.
  • Контролировать исполнение — напоминать о необходимости оформления данного действия, в случае возникновения событий, указанный в табличной части События.
    • Срок исполнения — количество дней, в течение которых должно быть оформлено данное действие, после возникновения события.
  • Не разбивать на страницы — отключить автоматическое разбиение на страницы формы отчетности.
  • Выводить номер страницы — для тех форм, где это предусмотрено, включает вывод номера страницы сверху формы.

Виды иностранных работников

Указывается, для каких видов иностранных работников должно происходить автоматическое добавление этого действия при заполнении документа Отчетность по иностранным работникам.

События

Указывается, при каких событиях должно происходить автоматическое добавление этого действия при заполнении документа Отчетность по иностранным работникам. Также по данным событями происходит контроль исполнения действия.
