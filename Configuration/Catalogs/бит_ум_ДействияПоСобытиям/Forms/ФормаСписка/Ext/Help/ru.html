Действия по событиям

Справочник предназначен для хранения информации о действиях, которые нужно произвести при событиях, таких как прием на работу, прибытие и т.д., при учете иностранных граждан.

Этот справочник упрощает заполнение табличной части документа Отчетность по иностранным работникам, используется при нажатии на кнопку «Заполнить по событию».

По кнопке «Создать» можно добавлять новые виды событий, используемые в работе при ведении учета иностранных работников.
