Основание для работы без разрешения

Предназначен для хранения списка оснований, по которым иностранные граждане имеют права работать без патента или разрешения на работу. Используется в некоторых формах отчетности.

Реквизиты

  • Наименование — название документа основания, которое будет выводиться в формах списка и выбора.
  • Полное наименование для печати — наименование, которое будет выводиться в формы отчетности.
