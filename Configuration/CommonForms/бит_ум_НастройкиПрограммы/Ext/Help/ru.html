Настройка параметров учета

Форма предназначена для установки параметров ведения учета, которые являются общими для всех организаций информационной базы.

Настройка «Учет нескольких патентов у одного работника» включает разделение патентов по разрезам. Доступна, только если включен «Учет патентов». Пока настройка выключена, поле «Разрез» нигде не отображается и программа работает как прежде — один патент на работника.
