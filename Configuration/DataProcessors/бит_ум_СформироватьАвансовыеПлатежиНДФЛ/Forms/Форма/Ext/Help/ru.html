Сформировать авансовые платежи НДФЛ

Обработка используется для автоматического формирования документа «Авансовый платеж иностранца по НДФЛ» по сотрудникам, которые вносили плату за патент. Используется только в конфигурациях, где присутствует данный документ (ЗУП, ERP).

Имеет обязательные реквизиты для заполнения:

  • Организация — организация, по которой будут формироваться документы.
  • Налоговый период — год, налоговый период за который будут сформированы документы.

Предусмотрено автоматическое заполнение табличной части документа кнопкой Заполнить сотрудниками, которые вносили плату за патент за указанный период. При заполнении отбираются сотрудники по указанной организации, у которых получено подтверждение права на уменьшение суммы НДФЛ за указанный налоговый период и у которых имеются квитанции за указанный период за указанный месяц (если отборы заданы).

При нажатии кнопки Сформировать документы, для каждой строчки табличной части «Платежи», отмеченной флагом, формируется документ «Авансовый платеж иностранца по НДФЛ». Если документ уже существовал (значение в колонке Документ), то он перезаписывается новыми данными.
