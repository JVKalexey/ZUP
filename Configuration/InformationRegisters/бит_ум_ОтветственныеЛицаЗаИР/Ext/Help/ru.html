Этот регистр предназначен для хранения информации ответственных лиц организаций за иностранными работниками. Данные этого регистра используется для формирования различных видов документов иностранных работников организации, которые несут ответственность за учет иностранных работников и сдачу отчетности по ним в контролирующие органы.
