Иностранный работник

Этот регистр предназначен для хранения дополнительной информации иностранного работника для контроля и сдачи отчетности в контролирующие органы.

Реквизиты

  • Физ. лицо — физическое лицо, для которого заносится информация.
  • Режим въезда — режим въезда иностранного работника в РФ.
  • Статус — статус иностранного работника в РФ.
  • Дата прибытия — дата прибытия иностранного работника в РФ.
  • Дата убытия — дата убытия иностранного работника из РФ.
  • Дата окончания работы — планируемая дата окончания трудовой деятельности в РФ.
  • В документы добавлять вручную — при автоматическом заполнении документа Отчетность по иностранным работникам, пропускать данного работиника.
  • Запись действут с — дата, с которой начинают действовать введенные данные о документе. Обычно совпадает с датой выдачи документа.
