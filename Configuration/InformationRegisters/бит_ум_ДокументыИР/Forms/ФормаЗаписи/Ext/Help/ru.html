Документ иностранного работника

Регистр предназначен для хранения информации о документах иностранных работников организации, таких как миграционная карточка, разрешение на работу, паспорт иностранного гражданина и т.д. Виды этих документов регистрируется в системе справочником Виды документов иностранных работников.

Реквизиты

  • Физ. лицо — физическое лицо, для которого заносится информация о документе.
  • Вид документа — вид документа, о котором заносится информация, например, паспорт или виза.
  • Разрез — разделяет несколько одновременно действующих документов одного вида, например два патента. Поле отображается только у тех видов документов, для которых установлен признак Использовать разрез, и только при включенном учете нескольких патентов. Незаполненный разрез означает основной документ.
  • Серия — серия документа, при наличии.
  • Номер — номер документа.
  • Дата выдачи — дата выдачи документа.
  • Срок действия — дата, по которую действует документ.
  • Государственный орган — государственный орган, который выдал документ.
  • Территория действия — территория действия документа. Если не указано, то территория действия будет определяться из территории действия государственного органа, указанного в соответствующем поле.
  • Запись действут с — дата, с которой начинают действовать введенные данные о документе. Обычно совпадает с датой выдачи документа.
  • Архив — признак того, что документ помещен в архив. Такие документы в списке не подкрашиваются желтым и красным цветом фона, в случае, когда подходит срок действия. А также не отображаются в отчетах по документам.
