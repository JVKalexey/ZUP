Отчет «Сверка ВГО (Произвольный)»

 

Отчет «Сверка ВГО (Произвольный)» (меню «Управленческий») позволяет выверить суммы внутригрупповых оборотов по счетам выбранного плана счетов.  План счетов, по которому будут анализироваться внутригрупповые операции, выбирается по кнопке «Выбрать вариант».

 

В отчете выводится организация, ЦФО, собственный контрагент, счет, сумма дебетового оборота, сумма кредитового оборота, отклонение (разница Дт-Кт). В случае отсутствия расхождений по отражению внутригрупповых операций у компаний Группы, итоговая сумма в колонке «Оборот Дт» равна итоговой сумме в колонке «Оборот Кт». В итоговой строке по колонке «Отклонение» должен получиться ноль.  

 

Примечание. При формировании данного отчета используются настройки, выполненные в регистре «Собственные контрагенты (БИТ)».

 

По двойному щелчку правой кнопкой мыши на ячейке можно расшифровать сумму ячейки по субконто счетов и регистратору (документу, сформировавшему оборот по бюджету).

 

В настройках пользователя можно задавать различные условия отбора (например, по конкретным статьям оборотов, ЦФО, контрагентам и т.п.).
