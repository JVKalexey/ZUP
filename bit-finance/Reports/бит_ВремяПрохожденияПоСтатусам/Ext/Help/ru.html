Отчет «Время прохождения по статусам»

 

Отчет «Время прохождения по статусам»  (меню «Операции» - «Отчеты» - «Время прохождения по статусам») показывает количество часов и количество секунд по каждому статусу документов «Актуализация бюджета», «Дополнительные условия по договору», «Заявка на расходование», «Форма ввода бюджета», «Реестр платежей», «Корректировка бюджета». Можно установить отбор и сортировку по статусу, по периоду, по документу и т.д.
