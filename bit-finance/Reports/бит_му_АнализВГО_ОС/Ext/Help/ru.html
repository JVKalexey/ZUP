Отчет по основным средствам


Для контроля эксплуатационных параметров основного средства в системе реализован отчет, который отражает данные по перечню ОС.

По кнопке «Настройка варианта отчета - Настройка структуры» открывается форма, в которой можно настроить произвольную структуру отчета (изменить состав строк и столбцов), задать период формирования отчета, установить различные отборы и сортировки, изменить цветовое оформление отчета.

По кнопке «Сохранить вариант отчета» можно сохранить сделанные настройки отчета для последующей работы с ним. Сохраненные варианты отчета можно просмотреть, нажав на заголовок этого варианта в верхней панели формы отчета (панель вариантов). По кнопке «Отображение панели вариантов» можно отобразить или скрыть панель вариантов.

По кнопке «Действия со сформированным отчетом» можно сформировать отчет в отдельном окне, сохранить отчет и сравнить сформированный отчет с сохраненным.
