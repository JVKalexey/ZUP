Произвольный отчет

 

Отчет предназначен для вывода отчетов с фиксированным макетом. Отчет строится по данным справочника «Настройки произвольного отчета». 

 

В отчете существует возможность хранения вариантов отчетов. Варианты отчета привязаны к текущему пользователю.  Несколько вариантов настроек удобно использовать, если пользователь работает с определенными произвольными отчетами и ему необходимо быстро переключаться между ними.

 

Новый вариант отчета можно сохранить с помощью кнопки «Сохранить вариант отчета».

Сохраненные отчеты отображаются на панели вариантов.

 

По кнопке «Действия со сформированным отчетом» можно сформировать отчет в отдельном окне, сохранить отчет и сравнить сформированный отчет с сохраненным.
