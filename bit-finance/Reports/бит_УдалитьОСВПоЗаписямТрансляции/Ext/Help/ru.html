Отчет «Оборотно-сальдовая ведомость по записям трансляции»


Примечание: Данный отчет предназначен для анализа результатов трансляции из регистра «Журнал проводок (бухгалтерский и налоговый учет)» в регистр «Журнал проводок (международный)»


Отчет «Оборотно-сальдовая ведомость по записям трансляции» позволяет проанализировать соответствие оборотов трансляции источника и приемника одновременно в разрезе счетов учета регистра-источника и регистра-приемника.


В отчете реализовано два предопределенных варианта отчета:

  • Разворот по источнику – позволяет получить расшифровку счетов источника по счетам приемника. Например, в случае трансляции данных из РСБУ в МСФО отчет отображает информацию о том, на какие счета МСФО оттранслировался тот или иной счет РСБУ и какие обороты вообще не были оттранслированы.
  • Разворот по приемнику – позволяет получить расшифровку счетов приемника по счетам источника. Например, в случае трансляции данных из РСБУ в МСФО отчет отображает информацию о том, из каких счетов РСБУ сложились движения по тому или иному счету МСФО и какие обороты были сформированы документами параллельного учета подсистемы МСФО.

Для переключения между предопределенными вариантами необходимо использовать кнопку «Выбрать вариант»


Отчет отображает следующие данные:

  • Остатки по счетам только верхнего уровня группировки. Например, в случае трансляции данных из РСБУ в МСФО для варианта отчета «Разворот по источнику» будут отображаться остатки только по счетам РСБУ.
  • Обороты по счетам, как верхнего разворота, так и нижнего разворота. Например, в случае трансляции данных из РСБУ в МСФО для варианта отчета «Разворот по источнику» будут отображаться обороты по счетам РСБУ в разрезе счетов МСФО


По двойному щелчку левой кнопкой мыши на ячейке можно расшифровать сумму ячейки по аналитикам и регистратору (документу, сформировавшему проводку).
