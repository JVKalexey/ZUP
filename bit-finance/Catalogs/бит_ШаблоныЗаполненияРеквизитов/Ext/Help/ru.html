Справочник «Шаблоны заполнения реквизитов»

 

В справочнике «Шаблоне заполнения реквизитов» хранятся шаблоны заполнения реквизитов объектов. На данный момент заполнение по шаблону возможно только для реквизита "Номер договора" в документе "Проект договора".


Шаблон заполнения реквизита может быть создан с помощью конструктора шаблона, которой можно вызвать по команде "Вставить шаблон" в командной панели элемента справочника.
