Обработка «Сводный бюджет»


Обработка предназначена для ввода плановых данных с произвольными группировками аналитик в строках.


Ввод данных по статье оборотов осуществляется в отдельном окне, которое открывается при двойном щелчке мышью по ячейке. Данные по статье можно расшифровать по любым управленческим аналитикам.


Из формы обработки по команде «Создать документы» создаются документы «Бюджетная операция».
